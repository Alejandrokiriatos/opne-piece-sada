SERVIDOR Y NOTIFICACIONES

Conexión de Butterfly Café

Introduce la URL HTTPS del servidor API desplegado y el token administrativo. La URL se guarda en el catálogo compartido; el token se cifra en Android y nunca se publica en GitHub.

Configuración pendiente

Enviar aviso a los clientes

Los dispositivos deben haber aceptado las notificaciones y registrarse previamente.

Servicios externos

La API usa Cloudflare Workers + D1 para pedidos y base de datos. Para Android, Firebase Cloud Messaging necesita un proyecto Firebase y un archivo de configuración para cada aplicación Android. Las claves privadas se guardan como secretos del servidor y nunca en el catálogo.
